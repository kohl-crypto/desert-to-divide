# Desert to Divide 🏜️ → 🏔️

Mari's interactive road-trip tour guide: Phoenix → Grand Canyon → Monument Valley → Arches → Ouray → Black Canyon → Woodland Park (Nov 8–11, 2026).

**Open the app:** https://kohl-crypto.github.io/desert-to-divide/

**Downloads:** [PowerPoint tour guide](Desert-to-Divide-Tour-Guide.pptx) · [Offline app (one HTML file)](index.html)

## What's in the app
- A waving Estonian flag welcome (2 seconds)
- A day-by-day timeline with check-offs, saved on the phone
- 4 epic hikes with A/B/C options, plus quirky roadside stops
- Two food picks for every meal and three Airbnb picks per night
- A countdown to the Wednesday 2 PM finish
- A Buc-ee's brisket **gobble button** 🦃
- Pastel theme with dark mode, accessible tap targets and reduced-motion support

## Reuse it for another trip
See [CLAUDE.md](CLAUDE.md). In short: edit `src/data.js` (and optionally `src/art.js`), then run `node src/build.js` and `node src/deck.js`.
